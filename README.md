เข้าไปใน Main แล้วใช้ build_all.bat เพื่อ gcc ทุกไฟล์ออกมาจะได้ไฟล์ชื่อ app 
หรือถ้ามีปัญหารันแล้วไม่ได้ app.exe ออกมา ให้ใช้ app.exe ที่มีในนั้นได้เลย

ปัญหาที่เจอ
-พอเรียก Unit Test กับ E2E Test แล้วจะไม่สามารถกลับไปหน้าเมนูได้ มีทางเดียวคือปิดโปรแกรมเปิดใหม่
-ไม่มั่นใจว่า Unit Test กับ E2E Test ทำถูกตามความต้องการของอาจารย์หรือไม่

หากไม่สามารถเรียก unit test กับ E2E Test สามารถเข้าไปดูผลการ Test ได้ใน Folder "all test'
